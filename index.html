About me

I'm a software engineer from Nigeria who likes building things that work: clean code, quick pages and systems that stay up.

I take on projects of any size and care about the same things in each one. You should understand what's happening, trust the result and be able to build on it later.

What I do

  • Front end developer

    I build the screens people use: fast, responsive and easy to use on any device.

  • Back end developer

    I build the servers, databases and APIs behind the screen, and keep them quick and secure as usage grows.

  • AI and ML architect

    I design how a system fits together and add machine learning where it genuinely helps, from planning the data to putting the model live.

How a project goes

Writing code is only part of the job. This is the whole path from idea to launch.

  1. Understand

    We talk through who it's for and what it needs to achieve. I write that down so we agree before I start.

  2. Build

    I build in small pieces you can see and test, with clean code the next developer can pick up.

  3. Test and secure

    I test it, check security and fix problems before anyone else sees them.

  4. Launch

    I put it online, set up automatic updates and stay available for fixes and changes.

Why work with me

  • You always know where things stand

    Short, plain updates: what's done, what's next and what I need from you.

  • Honest timelines and prices

    I scope the work clearly, quote fairly and tell you early if something changes.

  • I stay after launch

    Fixes, small changes and new ideas don't end at handover.
